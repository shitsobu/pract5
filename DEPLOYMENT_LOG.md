# Журнал развёртывания Attendance Service

## 1. Общие сведения

**Дата выполнения:** 17.11.2026  
**Приложение:** Attendance Service  
**Версия:** 0.5.0  
**Docker-образ:** `edu/attendance-service:v0.5.0`  
**Среда:** Windows + Docker Desktop  
**Режим развёртывания:** автономный, без обращения к внешнему реестру.

## 2. Ход выполнения работ

| № | Выполненное действие | Команда или инструмент | Результат |
|---|---|---|---|
| 1 | Проверка конфигурации Docker Compose | `docker compose config` | Успешно |
| 2 | Сборка Docker-образа | `docker build -t edu/attendance-service:v0.5.0 .` | Образ собран |
| 3 | Сохранение образа в архив | `docker save -o release\attendance-v0.5.0.tar edu/attendance-service:v0.5.0` | Архив создан |
| 4 | Вычисление контрольной суммы | `certutil -hashfile release\attendance-v0.5.0.tar SHA256` | SHA256 получен |
| 5 | Запуск приложения | `docker compose up -d` | Контейнер запущен |
| 6 | Проверка состояния контейнера | `docker compose ps` | Контейнер работает |
| 7 | Проверка API | Запросы `/health`, `/attendance` | Получены корректные ответы |
| 8 | Проверка обработки ошибок | Запрос `/unknown` | Получен HTTP 404 |
| 9 | Создание резервной копии данных | `docker cp pract5-attendance:/data/state.json backup\state.json` | Копия создана |
| 10 | Проверка резервной копии | Копирование в `backup\restore` | Файл восстановлен в отдельный каталог |
| 11 | Проверка сохранности данных | `docker compose restart attendance` | Данные сохранились |
| 12 | Сбор показателей ресурсов | `docker stats --no-stream pract5-attendance` | Получены показатели |
| 13 | Проверка журналов | `docker compose logs --tail=20 attendance` | Журналы получены |
| 14 | Остановка приложения | `docker compose down` | Контейнер остановлен |
| 15 | Имитация отказа | `docker rmi edu/attendance-service:v0.5.0` | Локальный тег удалён |
| 16 | Проверка архива | `certutil -hashfile release\attendance-v0.5.0.tar SHA256` | Контрольная сумма совпала |
| 17 | Восстановление образа | `docker load -i release\attendance-v0.5.0.tar` | Образ загружен |
| 18 | Автономный повторный запуск | `docker compose up -d --pull never` | Контейнер запущен |
| 19 | Финальная проверка | `docker compose ps` и запрос `/health` внутри контейнера | Статус healthy, HTTP 200 |

Приложение успешно собрано и запущено в Docker-контейнере. Выполнены проверки доступности API, обработки некорректного маршрута, сохранности данных и работоспособности контейнера после перезапуска.
