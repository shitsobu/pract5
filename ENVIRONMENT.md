# Паспорт среды развёртывания

## 1. Назначение

Среда предназначена для автономного развёртывания и проверки приложения Attendance Service версии 0.5.0.

## 2. Программное обеспечение

| Компонент | Назначение |
|---|---|
| Windows | Операционная система |
| Docker Desktop | Контейнерная среда |
| Docker Engine | Запуск контейнеров |
| Docker Compose | Управление развёртыванием |
| Python 3.12 | Среда выполнения приложения внутри контейнера |

## 3. Параметры приложения

| Параметр | Значение |
|---|---|
| Имя контейнера | pract5-attendance |
| Docker-образ | edu/attendance-service:v0.5.0 |
| Внутренний порт | 8006 |
| Настроенный локальный порт | 8106 |
| Каталог данных | /data |
| Переменная версии | APP_VERSION=0.5.0 |
| Лимит памяти | 128 MiB |
| Сеть | pract5-isolated |

## 4. Сетевая изоляция

Для приложения настроена внутренняя Docker-сеть с параметром `internal: true`. Внешний доступ к реестрам контейнеров при автономном запуске не требуется.

Проверка API выполняется локально внутри контейнера.

## 5. Хранение данных

Постоянные данные размещаются в Docker volume `pract5-data`.

Резервная копия хранится в каталоге `backup`. Офлайн-архив Docker-образа находится в каталоге `release`.

## 6. Вывод

Подготовлена изолированная среда для автономного запуска приложения. Конфигурация, данные и Docker-образ хранятся отдельно от исходного кода.
