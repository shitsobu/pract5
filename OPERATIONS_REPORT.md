# Эксплуатационный отчёт Attendance Service

## 1. Общие сведения

Приложение: Attendance Service  
Версия: 0.5.0  
Дата проверки: 17.11.2026  
Среда: Windows + Docker Desktop  
Docker-образ: `edu/attendance-service:v0.5.0`

## 2. Результаты эксплуатации

В ходе практической работы приложение было собрано и запущено в Docker-контейнере. Для хранения данных использовался постоянный Docker volume. Для контроля работоспособности настроен механизм HEALTHCHECK.

Проверены следующие функции:

- получение данных о посещаемости через `/attendance`;
- проверка состояния приложения через `/health`;
- обработка неизвестного маршрута с ответом HTTP 404;
- сохранение данных после перезапуска контейнера;
- просмотр журналов приложения;
- контроль потребления ресурсов.

## 4. Проверка отказоустойчивости

Для проверки восстановления был удалён локальный тег Docker-образа версии 0.5.0.

Перед восстановлением проверена контрольная сумма офлайн-архива SHA256. Затем образ загружен командой `docker load`.

После восстановления приложение запущено с параметром `--pull never`, исключающим обращение к внешнему реестру.

Контейнер перешёл в состояние `healthy`, проверка `/health` вернула HTTP 200.

## 5. Вывод

В результате эксплуатации подтверждена работоспособность приложения, сохранение данных при перезапуске, наличие журналов и контроль состояния контейнера. Также успешно проверено восстановление Docker-образа из офлайн-архива без обращения к внешнему реестру.
